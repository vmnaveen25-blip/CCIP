# CCIP / Astraea Enclave — Government-Grade UI Refinement Plan

## Summary

This plan elevates the existing CCIP/Astraea Enclave frontend into a polished, professional, government-grade cybercrime intelligence platform. The backend, APIs, authentication, and role portals are all working — this is a purely frontend UI/UX refinement pass.

**Technology audit:**
- React 18 + TypeScript + Vite
- Tailwind CSS (no Framer Motion installed)
- `lucide-react` icons, `recharts` charts, `clsx`, `tailwind-merge`
- No animation library installed → will use **CSS transitions + keyframes exclusively**
- Good design token foundation already exists in `index.css` + `tailwind.config.js`

---

## UI/UX Audit (Before Changes)

### Critical Issues
1. **No motion system** — page transitions are bare `animate-in` classes with no coordinated easing/timing system
2. **No reduced-motion respect** — no `@media (prefers-reduced-motion)` handling
3. **Sidebar** lacks active rail glow, hover brightness, smooth transitions
4. **Header** missing live WebSocket-status-aware pulse, DEFCON indicator is static
5. **Toasts** are single-line, no type variants, no queue system
6. **Buttons** missing `focus-visible` ring, `loading` states, `active` press animation
7. **Inputs** missing focus glow refinement, no inline validation animation
8. **Notification drawer** appears with abrupt snap (class-based CSS animation only)
9. **Portal switching** has no page-enter animation (just conditional render)
10. **Glass panels** missing consistent `inset` top highlight across all usages
11. **Tables** no sticky headers, no skeleton rows on load
12. **Empty states** generic ("No data")
13. **AI Detection Lab** probability bars are static (no animated fill)
14. **Model status badges** use hardcoded color classes, not semantic token variants
15. **AI triage** has no processing animation sequence
16. **Evidence upload** missing SHA-256 hash reveal animation
17. **Complaint timeline** steps appear statically
18. **Investigation Assistant** typing indicator shown even when not generating
19. **Cards** hover lift too aggressive (2px translateY works, but no scale micro-animation)
20. **AuthModal** no enter animation (full page render)

## Open Questions

> [!IMPORTANT]
> The existing codebase has no animation library installed (no Framer Motion). All motion will be implemented via CSS keyframes and Tailwind transitions. This is correct per spec ("prefer CSS transitions first"). No new npm packages will be added unless critical.

> [!NOTE]
> The `animate-in`, `fade-in`, `slide-in-from-top-2` classes used in the existing code are **Tailwind CSS Animate** utilities — these require the `tailwindcss-animate` plugin OR they work as custom Tailwind variants. We will verify if these are actually working or replace with explicit CSS keyframes.

> [!NOTE]  
> Portal page transitions will use React `key` prop on the portal wrapper to force re-mount, which triggers the CSS enter animation cleanly without requiring a state machine.
