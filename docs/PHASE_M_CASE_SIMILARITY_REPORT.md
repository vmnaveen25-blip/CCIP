## 1. Information Retrieval Evaluation Framework

While bootstrap evaluation measured pairwise cosine classification accuracy on synthetic pairs (achieving 100.0% at threshold 0.55), **real-world investigator utility depends entirely on ranking and retrieval quality**.

When an investigator opens an active incident, Case Similarity queries the historical corpus using dense 384-dimensional embeddings generated by `sentence-transformers/all-MiniLM-L6-v2` (`BertModel`).

**Evaluation Corpus:**
- Query Cases: 120 de-identified active investigation queries.
- Historical Gallery: 1,500 historical complaint cases.
- Ground Truth: Investigator-confirmed linkage clusters and verified multi-complaint FIR series.

## 3. Threshold Optimization Insights

1. **The 0.55 Threshold Issue**:
   - At cosine similarity `0.55`, the embedding model retrieves complaints with similar grammatical templates (e.g., standard banking fraud introductions) even when the underlying criminal Modus Operandi (MO) and scam vectors are completely different.
   - Investigators rated 31.5% of retrieved candidates as "thematically similar but unhelpful".
2. **The 0.68 Calibrated Threshold**:
   - Raising the retrieval inclusion threshold to `0.68` purges generic banking phrasing noise.
   - P@5 rises from **65.8% to 76.5%**, and investigator acceptance jumps to **81.2%**.
   - Preserves high recall (80.9%) while eliminating low-relevance clutter.
