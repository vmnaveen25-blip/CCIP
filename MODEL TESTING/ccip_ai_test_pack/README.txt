CCIP AI Model Test Pack

Contents:
- ccip_ai_model_test_runner.py: standard-library HTTP test runner for local/staging CCIP
- CCIP_AI_Model_Test_Matrix.csv: test cases, conditions, expected status/score fields and prerequisites
- CCIP_AI_Model_Testing_Guide.md: model inventory, run instructions, score interpretation and validation criteria

Start with the Guide. The current repo is not executed by this package; you need a running CCIP API for actual observed scores/statuses. Do not use mutating tests on production data.
